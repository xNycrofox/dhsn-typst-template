# Useful Packages

Below is a list of packages to consider if you need support for a certain task.
Packages are downloaded automatically from [Typst Universe](https://typst.app/universe/) when they are imported.

## Syntax Highlighting

Syntax highlighting is built into Typst and styled by the template, see [environments](./environments).
Check out [codly](https://typst.app/universe/package/codly) if you need more features like highlighted lines or annotations. Use it together with `codetheme: none`.

## Drawing diagrams

Check out [cetz](https://typst.app/universe/package/cetz), [fletcher](https://typst.app/universe/package/fletcher) and [chronos](https://typst.app/universe/package/chronos) for sequence diagrams.
Alternatively use any tool you like and include an image.

## Abbreviations

The template manages abbreviations on its own. Check out [glossarium](https://typst.app/universe/package/glossarium) if you need plural forms or other advanced features.

## Embedding or attaching files

Check out the built-in [pdf.attach](https://typst.app/docs/reference/pdf/attach/) function.
