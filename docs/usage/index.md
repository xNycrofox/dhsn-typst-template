# Usage

- [Typst Basics](./basics) explains the parts of Typst required to write a paper.
- [Simple Mode](./simple) configures everything with a single function.
- [Normal Mode](./normal) allows to arrange the parts of the paper yourself.
- [Environments](./environments) describes figures, tables, code and the appendix.
- [Citations](./citations) describes citations and the bibliography.
- [Reference](./reference) lists all functions and their arguments.
- [Useful Packages](./packages) lists packages for certain tasks.


::: tip
There is plenty of information around Typst available in the internet. For detailed information it is worthwhile to look up a function in question in the [Typst reference](https://typst.app/docs/reference/) and to search for packages on [Typst Universe](https://typst.app/universe/).
:::
