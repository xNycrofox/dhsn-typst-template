# Nützliche Pakete

Eine Liste von Paketen, die bei bestimmten Aufgaben helfen.
Pakete werden beim Import automatisch von [Typst Universe](https://typst.app/universe/) heruntergeladen.

## Syntaxhervorhebung

Syntaxhervorhebung ist in Typst eingebaut und wird vom Template gestaltet, siehe [Umgebungen](./environments).
Für mehr Funktionen wie hervorgehobene Zeilen oder Anmerkungen eignet sich [codly](https://typst.app/universe/package/codly), zusammen mit `codetheme: none`.

## Diagramme zeichnen

Geeignet sind [cetz](https://typst.app/universe/package/cetz), [fletcher](https://typst.app/universe/package/fletcher) und für Sequenzdiagramme [chronos](https://typst.app/universe/package/chronos).
Alternativ nimmt man ein beliebiges Werkzeug und bindet ein Bild ein.

## Abkürzungen

Das Template verwaltet Abkürzungen selbst. Wer Pluralformen oder andere weitergehende Funktionen braucht, findet sie in [glossarium](https://typst.app/universe/package/glossarium).

## Dateien einbetten oder anhängen

Dafür gibt es die eingebaute Funktion [pdf.attach](https://typst.app/docs/reference/pdf/attach/).
