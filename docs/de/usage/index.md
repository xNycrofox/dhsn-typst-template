# Benutzung

- [Typst-Grundlagen](./basics) erklärt die Teile von Typst, die man zum Schreiben einer Arbeit braucht.
- [Einfacher Modus](./simple) konfiguriert alles mit einer einzigen Funktion.
- [Normaler Modus](./normal) erlaubt es, die Teile der Arbeit selbst anzuordnen.
- [Umgebungen](./environments) beschreibt Abbildungen, Tabellen, Quelltext und den Anhang.
- [Zitate](./citations) beschreibt Zitate und das Literaturverzeichnis.
- [Referenz](./reference) listet alle Funktionen und ihre Argumente auf.
- [Nützliche Pakete](./packages) nennt Pakete für bestimmte Aufgaben.

::: tip
Im Internet gibt es viele Informationen rund um Typst. Für Details lohnt es sich, eine Funktion in der [Typst-Referenz](https://typst.app/docs/reference/) nachzuschlagen und auf [Typst Universe](https://typst.app/universe/) nach Paketen zu suchen.
:::
